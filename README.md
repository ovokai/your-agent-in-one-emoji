## The entry

🦉 — the owl. An AI agent watches everything, stays up all night working
while you sleep, and acts quietly and wisely on what it sees. One glyph,
no explanation needed.

## Run it

```sh
node main.ts
```

This writes the single emoji to `/output/entry.txt` (falling back to a
local `entry.txt` when `/output` is not writable).
